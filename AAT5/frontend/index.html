WordNet Synonyms, Definitions & Context

Lists every WordNet sense of a word with its definition and synonyms, then uses the Lesk algorithm to pick the sense used in each sentence. This page calls http://localhost:5005/api/wordnet.

How to read the output

Each synset is one meaning. n = noun, v = verb, a/s = adjective, r = adverb. Lesk chooses the sense whose dictionary gloss overlaps most with the sentence, so it can be wrong on short sentences.
